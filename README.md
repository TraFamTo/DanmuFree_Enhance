B站 / 抖音直播间弹幕桌面客户端（Windows）。把弹幕 / 礼物 / 进场关注 / 统计展示在可悬浮、半透明的桌面窗口里；悬浮模式**真·鼠标穿透**，打游戏开着也不挡操作。协议层完全自写（零第三方直播库）。

![DanmuFree 截图](assets/screenshot.png)

## 项目来源

本项目 **DanmuFree_Enhance** 基于 [SoraYjy/DanmuFree](https://github.com/SoraYjy/DanmuFree) 修改，原作者为 **Sora（SoraYjy）**。本次开发以原项目 v1.0.10 对应的提交 [`5fec53f`](https://github.com/SoraYjy/DanmuFree/commit/5fec53f) 为基础，面向主播在自己的 B站直播间使用，增加直播统计和房间管理功能。

原项目提供 B站 / 抖音弹幕连接、悬浮窗口、通知、弹幕朗读及定向回复等基础功能。本仓库在此基础上扩展，沿用 **MIT 许可证**，保留原作者版权声明，详见 [LICENSE](LICENSE)。

## 本版本改动

以下新增功能目前只支持 **B站**：

- **弹幕外观与身份徽章**：新增直播姬风格的半透明圆角消息卡片，粉丝灯牌展示名称、等级及消息提供的颜色，未点亮时淡化；舰长 / 提督 / 总督、房管及主播分别显示徽章，房管与航海身份可同时显示。控制面板可独立开关灯牌、航海和身份徽章，也可切回原版文字样式。
- **开播累计时长**：在「赞」之后依次显示「收入（已记录）」和开播时长，按服务器开播时间每秒更新；同一场直播断开后重连，时长继续计算。
- **上次直播汇总**：未开播时，在控制面板显示最近一次直播的时长和后台总收入，优先在线查询当前登录主播自己的直播记录；悬浮窗不显示上次汇总。
- **本场收入估算**：统计付费礼物、上舰和 SC，按指定的 50% 折算人民币；去重并保存本场累计值，同一场直播重连或重启后继续累计。实时统计只能覆盖程序接收到的消息，断线期间的收入需在下播后通过后台总收入查看。
- **房管管理**：控制面板增加与原有页面并排的标签页，支持查看房管名单、按 UID / 昵称查找用户、任命和撤销房管。
- **禁言管理**：控制面板增加独立标签页，支持从最近弹幕选人或搜索 UID / 昵称，禁言、查看禁言名单及解禁；管理操作前验证当前登录账号是否为该直播间主播。
- **单份汇总与断开清理**：直播记录只保留最近使用房间的一份汇总，新记录覆盖旧记录；断开后清空临时列表并取消网络、心跳和朗读任务，同一场仍在直播时保留重连所需的累计值与去重信息。日志轮换，只保留当前文件和一个备份。

同时完善了连接释放、取消请求和消息队列清理，并增加相关自动化测试。验证结果为 **246 项测试通过**，解决方案构建 **0 警告、0 错误**；主播身份、历史汇总、名单读取和用户搜索已做真实账号只读验证，任免和禁言写操作使用模拟接口测试。

## 功能地图

| 模块 | 说明 |
|---|---|
| **双平台** | B站（扫码登录）+ 抖音（匿名免登录），共用一套展示管道 |
| **弹幕窗** | 纯聊天弹幕列表；粉丝勋章 / 时间戳；用户名·正文分开字体颜色；消息可设 N 秒后自动消失；千条虚拟化 + 高弹幕量滚动合并不丢不卡 |
| **通知窗（独立）** | 进场 / 关注 / 礼物·舰长 / SC，四类分开关闭，金色加粗，可显时间戳、可设自动消失，不混进聊天流 |
| **统计** | 在线 / 看过 / 点赞 常驻顶部（B站 WS 实时推送**真实在线人数**，不推的房间回落人气值；抖音 WS 实时推送）；B站按「赞 → 收入（已记录）→ 开播时长」排列，时长每秒更新、支持超过 24 小时；开播状态通过 WS 推送与每分钟轮询同步，抖音不显示收入和时长 |
| **悬浮沉浸** | 真·鼠标穿透（`WS_EX_TRANSPARENT`），全屏 / 无边框游戏不挡操作、不抢焦点；悬浮态抗 Win+D（被最小化会自动恢复） |
| **弹幕朗读** | 三引擎：**Edge 在线**（Azure 神经音，零配置·默认·14 中文音色）+ GPT-SoVITS 克隆 + 系统内置；礼物连送聚合不刷屏 |
| **定向回复** | 弹幕命中关键词 → 不读原文，改念固定回复或播放音效（wav/mp3）；多条规则从上往下、首条命中即停；总开关一键启停，每条可勾选临时禁用 |
| **房管管理（B站）** | 控制面板独立标签页：读取房管名单、按 UID / 昵称搜索用户、任命与撤销房管；自动核对登录账号是否为当前房间主播 |
| **禁言管理（B站）** | 控制面板独立标签页：从最近 200 条弹幕选人，或按 UID / 昵称查找；禁言 1 / 24 / 168 / 720 小时、查询禁言名单、按用户解禁 |
| **持久化** | cookie / 窗口位置·大小 / 悬浮态 自动存盘，重开还原 |

> 弹幕聊天与礼物 / SC / 进场关注分两路：聊天在弹幕窗，事件在通知窗。

## 怎么用

### ① 原版下载

以下下载入口属于原项目，发布包不包含本仓库新增功能。体验本版本请使用下面的源码运行方式。

1. 到 [Releases](https://github.com/SoraYjy/DanmuFree/releases/latest) 下 **`DanmuFree-vX.Y.Z-win-x64.zip`**（~260MB，自带运行环境）
2. 解压到任意目录
3. 双击 **`DanmuFree.exe`** —— 无需装 .NET / Node

### ② 从源码运行本版本

需要 **.NET 8 SDK**；抖音签名与 Edge 在线朗读的 sidecar 还需本机 **Node.js**（PATH 里有 `node`；打包分发自带，用户机无需装）。
```bash
dotnet run --project src/DanmuFree.App                                   # debug 运行
# 或双击构建产物：src/DanmuFree.App/bin/Debug/net8.0-windows/DanmuFree.exe
./pack.sh                          # Git Bash 里打包绿色版 → dist/DanmuFree/
```
> Windows 的 **PowerShell / cmd 用 `.\pack.cmd`**（= pack.sh 的入口，别用 `.\pack.sh`——那会走 `.sh` 文件关联弹个 git-bash 窗口又秒关、看不到输出）。

### 登录 & 连接

- **B站**：控制面板 →「扫码登录」用手机 app 扫码（cookie 自动存，重开免重扫）→ 输房间号（短号即可）→「连接」
- **抖音**：免登录，顶部切到「抖音」→ 输 `live.douyin.com/` 后那串房号 →「连接」（首次约 2s，签名开销）

### 日常操作

- **调样式**：弹幕显示后，控制面板调字体 / 颜色 / 透明度 / 字号（实时生效）
- **B站身份徽章**：「弹幕」TAB 默认开启「直播姬风格（圆角消息卡片）」，可分别开关粉丝灯牌及等级、航海徽章、主播 / 房管徽章与昵称强调；关闭直播姬风格可恢复原版紧凑文字布局，抖音仍使用原版样式。开关会即时作用于已有消息，退出程序后保存设置。长弹幕自动换行，徽章字号随弹幕字号调整。
- **打游戏**：「弹幕」TAB 勾「**悬浮**」→ 弹幕窗置顶 + 鼠标穿透；打完取消勾选退出
- **读弹幕**：见下「弹幕朗读如何接入」

## 配置一览

| **进场/关注** | 接收进场 · 接收关注 · 显示通知窗 · 显示时间 · 保留秒数(0=永久) · 字号(8~100)/字体/透明度 · **文字描边** · **通知窗悬浮** |

| **定向回复** | **总开关** · 规则列表（加/删/排序/试听）· 关键词 · 回复方式（念文字 / 播音频）· 音频文件选择 |

### B站直播记录与收入

- **上次直播时长仅在控制面板显示**：未开播时显示「未开播-最后一次直播时长为02:15:36」，弹幕悬浮窗只显示「未开播」。优先使用登录主播账号自己的 B站后台历史记录（`AnchorGetReplayList`），按场次开播/下播时间相减，不使用录像文件时长；仅接受与当前真实房间号匹配的最近已结束场次，且不以尚未更新的旧场次覆盖较新的本地记录。后台回放列表有保存期限，接口也可能不可用，参见[接口说明](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/live/live_replay.md#获取直播回放列表)。失败时使用本地记录：收到带服务器时间的下播消息时按该时间计算，只靠轮询时标「约」，离线较久后才发现下播则用最后确认仍在直播的时间标「至少」。两种来源均无可用记录时显示「暂无记录」。连接时自动查询，未开播期间每分钟重试；鼠标悬停可查看时长来源。
- **收入（已记录）**：统计本场收到的付费礼物（兼容 SEND_GIFT / SEND_GIFT_V2）、上舰、SC，统一按指定的 50% 折算为人民币；免费银瓜子礼物不计。普通礼物优先使用实际支付总额，不叠加连击累计值，避免重复；带稳定交易号的消息去重。金额字段缺失的礼物无法计入。
- **上次总收入（后台，仅控制面板）**：未开播时，使用与上次直播时长相同场次的 `live_key` 查询 `StopLiveData.HamsterRmb`，直接显示后台返回的人民币收益，不再除以 2。连接时查询，未开播期间每分钟刷新，成功值自动保存。同一场次查询失败可保留缓存，换到其他场次时不会沿用旧金额；没有收入数据时显示「暂无数据」，有效零收入显示 `¥0.00`。悬浮窗仍只显示本场已记录收入，不显示上次收入。接口字段见[直播场次数据说明](https://github.com/pskdje/bilibili-API-collect/blob/main/docs/live/live_data.md#获取直播场次的直播数据)。
- **换算**：电池数 ÷ 10 ÷ 2；协议里的金瓜子金额 ÷ 2000；上舰单价金瓜子 × 数量 ÷ 2000；SC 人民币金额 ÷ 2。协议金额字段参考 [blivedm 的消息定义](https://github.com/xfgryujk/blivedm/blob/dev/blivedm/models/web.py)。
- **统计范围**：仅本程序接收到并保存的消息，无法补齐连接前、断线期间或程序关闭期间的收入，不代表平台结算账单。相同场次重连、重启继续累计，确认新场次时清零。只保留最近使用房间的一份汇总，切换房间覆盖旧房间记录；新场次结束覆盖上次汇总，不保存历史场次列表。
- **保存位置**：`%AppData%\DanmuFree\live-sessions.json`，使用真实房间号识别记录，整个文件只保留最近使用房间的一份汇总。更改记录后最多约 1 秒写盘，正常退出也会保存。

### B站房管与禁言管理

连接自己的 B站直播间后，控制面板的「房管管理」「禁言管理」会自动验证主播身份并读取名单。任免房管时从搜索结果或房管名单中选人；禁言时可以从最近弹幕、搜索结果或禁言名单中选人。数字输入按 UID 查询，其他内容按昵称搜索；最近发言用户会优先列出，在线搜索受限时可使用 UID。所有目标均显示 UID，操作后刷新对应名单。解禁会从服务器名单查找该 UID 的禁言记录，支持跨页查找，不把 UID 当成禁言记录编号。

管理入口只在控制面板，弹幕悬浮窗不增加操作按钮。程序从弹幕原始数据保留发送者 UID，无法取得 UID 的消息不作为管理目标。接口登录失效、权限不足、名额限制或操作失败会在页面提示。

**断开连接清理**：取消管理查询和统计轮询，关闭 WebSocket 与心跳，停止朗读并释放消息队列，清空弹幕、通知、最近发言、搜索结果、房管和禁言名单以及所选目标；旧请求和排队消息不能重新填回页面。这些临时数据不写入本地。管理页最近弹幕最多 200 条，每次搜索最多 40 个结果，名单按页读取。直播汇总只保留一份，已结束场次的交易去重明细会清空；仍在直播的场次保留必要去重数据以便重连续计。日志达到约 2 MB 后轮换，只保留当前文件和一个备份。

## 弹幕朗读如何接入

朗读读 **聊天 / SC / 礼物**，不读进场关注；朗读开关独立于显示（可"看着不读" / "不显示但读"）。三档引擎按需选：

**① Edge 在线（推荐 · 零配置）**：朗读 TAB 默认即此项 → 勾「启用」→「测试朗读」。调 Edge 浏览器的 Azure 神经音色（**14 个中文音色**：普通话 / 粤语 / 台湾 / 东北·陕西方言，下拉显示中文名），**免部署、免 key、免参考音频**，音质远胜系统内置、与 GPT-SoVITS 中性朗读持平。需联网（直播本就联网）；非官方端点，偶发失效时切系统内置兜底。

**② 系统内置（离线兜底）**：朗读 TAB → 选「系统内置」。用 Windows 自带中文语音（Huihui），零配置、离线可用，音色偏机械。

**③ GPT-SoVITS（要克隆音色才需要）**

GPT-SoVITS 是**独立的第三方音色克隆服务**，不在本项目内——部署、环境、模型、API 启动方式见其仓库：<https://github.com/RVC-Boss/GPT-SoVITS>（默认端口 9880）。

API 起好后，在 DanmuFree「朗读」TAB 选 **GPT-SoVITS**，填 **服务地址 + 3~10 秒参考音频 + 参考文本（音频里说的字）+ 语言** 即可。能克隆主播自己的声音，是它独有的卖点。

> 📊 **本机部署开销（实测）**：常驻内存约 **3.5 GB**；GPU 推理**官方主推 N 卡（CUDA）、开箱即用**（A 卡仅 Linux 下 ROCm 实验性、Windows 基本跑不通；Mac 走 MPS）；CPU 空闲时几乎不占、仅合成语音时瞬时拉高。无独显也能纯 CPU 跑（慢、更吃内存）。

**可选**：念用户名开关（开=「xx 说，…」，关=只读正文；礼物/SC 恒带用户名不受影响）· SC 念「xx 送了 N 元的 SC，内容」 · 语气滑块（采样温度，高丰富低平稳）· 礼物连送在 1200ms 内合并成「xx 送了 N 个 yy」· **不念用户**（用户名黑名单：这些人的弹幕不朗读，仍正常显示）。

**定向回复**（「朗读」旁独立 TAB）：弹幕命中关键词 → **不读这条弹幕**，改念一句你指定的话，或播放一段音效（wav/mp3）。多条规则**从上往下匹配、前面命中就不再看后面**；TAB 顶部有**总开关**，一键停用全部规则（配置保留）；每条规则前有勾选框，**不勾 = 临时禁用**（配置保留，随时勾回）。独立于「读弹幕」开关——可以关掉普通弹幕朗读、只播定向回复。典型用法：常问的问题（怎么加好友 / 几点下播）配一句固定答复，口号 / 梗配一段音效。支持加 / 删 / 上下移 / 试听，随设置自动保存。
